# Универсальный движок превью для стоматологий

Один репозиторий на GitHub + один проект на Vercel (`https://klinik-onizleme.vercel.app`).

## Как добавить новую клинику (за 30 секунд)
1. В папке `clinics/` создай файл `<короткое-имя>.json` (например `yildiz.json`, скопировав `parola.json` как образец).
2. Залей новый файл на GitHub → через 10 секунд заработает ссылка:
   `https://<твой-проект>.vercel.app/yildiz`

## Уже готовые клиники внутри
- `/` — нейтральное демо (если кто-то откроет корень без хвостика)
- `/kamerdent` — Başakşehir Kamerdent
- `/celikkaya` — Özel Çelikkaya (Serkan Naif Keleş, Negin Hanım, 09:00–19:00)
- `/parola` — Parola Diş (Dt. Ahmet Arap, Park Mavera 1, 7 дней 11:00–20:00)
